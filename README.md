# SpatioSam static site

A lightweight, responsive static website for Sam Chambers, designed for GitHub Pages.

## Files
- `index.html` — homepage
- `research.html` — research themes
- `publications.html` — selected publications
- `teaching.html` — teaching and mentoring
- `about.html` — biography, appointments, education, contact
- `assets/style.css` — all site styling
- `assets/site.js` — mobile navigation and copyright year

## Preview locally
Open `index.html` in a browser, or serve the folder with any simple local web server.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, deploy from the `main` branch/root.
4. Configure the custom domain as `spatiosam.com`.
5. Only after the GitHub Pages site works at its temporary GitHub URL, update DNS at Squarespace Domains.
