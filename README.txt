SPATIOSAM V3 — TWO-PAGE SITE

FILES TO UPLOAD TO YOUR spatiosam.github.io REPOSITORY:
- index.html
- publications.html

This version intentionally uses only two public pages:
1. Home — bio/about, current roles, brief teaching note, research themes, selected recent publications, contact
2. Publications — fuller publication list with ORCID and Google Scholar links

All CSS is embedded inside each HTML file. There are no external stylesheets, scripts, fonts, images, or folders required.

TO UPDATE ON GITHUB:
1. Upload index.html and publications.html and commit the changes.
2. Wait for GitHub Pages to redeploy and refresh https://spatiosam.github.io/.
3. Once the new version is working, delete the old research.html, teaching.html, and about.html files (and any old assets/files folders) if you want the repository cleaned up.
4. Do not add a CNAME or change Squarespace DNS until you are ready to move spatiosam.com from Google Sites to GitHub Pages.
